A beginner-friendly Python script that calculates fundamental descriptive statistics—specifically the mean, variance, and standard deviation—for any given list of numerical data.


* **Mean Calculation (`ortalama_hesapla`):** Finds the arithmetic average of the dataset[cite: 4].
* **Variance Calculation (`varyans_hesapla`):** Computes the population variance using squared differences from the mean[cite: 4].
* **Standard Deviation (`standart_sapma_hesapla`):** Derives the standard deviation by taking the square root of the variance[cite: 4].

Verilen herhangi bir sayısal veri listesi için temel istatistiksel değerleri (ortalama, varyans ve standart sapma) hesaplayan başlangıç seviyesinde bir Python betiği.


* **Ortalama Hesabı (`ortalama_hesapla`):** Veri setinin aritmetik ortalamasını bulur[cite: 4].
* **Varyans Hesabı (`varyans_hesapla`):** Ortalamadan sapmaların kareler toplamını kullanarak popülasyon varyansını hesaplar[cite: 4].
* **Standart Sapma (`standart_sapma_hesapla`):** Varyansın karekökünü alarak standart sapmayı elde eder[cite: 4].
